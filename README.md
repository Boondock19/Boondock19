### Things I've built

**Report pipeline that stopped timing out** · *GM Sectec*
Redesigned report generation as an ETL pipeline on AWS Glue, S3, Athena and DynamoDB. Reports that were hitting Lambda's 15-minute timeout now run in under 30 seconds, a 97% reduction, and yearly reports became possible for the first time.

**PCI DSS compliance tooling** · *GM Sectec*
Real-time monitoring services auditing HTTP headers and web resources loaded by client sites to meet PCI DSS 6.4.3 and 11.6.4, plus CSP report-processing APIs on Lambda, SNS and SES serving clients with up to 30,000 reports per month. Also built a processing workflow for encrypted TLV messages using the DUKPT key-management standard.

**Core modules of a fintech platform** · *Avila Tek*
Multi-currency management, exchange rates, transactions and account balances, and a loans module with simple and compound interest across monthly, quarterly and yearly schedules. Automated a bank reconciliation the client had been doing by hand, cutting its time by over 70%.

**Embeddable payment button and gateway** · *GCF Corp*
A PayPal-style payment button distributed via CDN so third-party sites could accept payments, plus the gateway that processes and reconciles those transactions, with multi-bank support and API-key self-service for clients.
